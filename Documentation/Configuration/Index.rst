=============
Configuration
=============

Configuring the extension has four parts, best done in this order:

#.  :ref:`configuration-webservice` -- store the Universal Messenger API
    credentials.
#.  :ref:`configuration-extension-configuration` -- set the storage page,
    the newsletter page type number, and other extension-wide defaults.
#.  :ref:`configuration-backend-user` -- grant editors rights on
    individual newsletter channels.
#.  :ref:`configuration-typoscript` -- include the rendering TypoScript
    and, optionally, the example newsletter template.
